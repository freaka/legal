Política de privacidade

TONY · assistente pessoal privado · atualizado em 27/10/2026

Quem usa

O TONY é usado só pelo seu dono, Alexandre Fonseca, com a conta Google dele. Nenhuma outra pessoa autoriza o acesso a dados próprios.

O que o TONY acessa no Google

Somente leitura da Google Agenda do dono (escopo calendar.readonly): os eventos das agendas que ele vê, para responder a perguntas como "o que tenho amanhã?", montar o resumo do dia e lembrar dos compromissos. O TONY não cria, muda nem apaga eventos, e não acessa e-mail, contatos ou arquivos.

Onde os dados ficam

Os eventos são lidos e mantidos num computador doméstico do dono. Quando o dono faz uma pergunta sobre a agenda, os eventos do período perguntado podem ser enviados ao provedor do modelo de IA que responde (Anthropic), apenas para produzir a resposta ao próprio dono.

O que o TONY não faz

Não vende, não compartilha e não usa os dados para publicidade. Não transfere os dados a terceiros além do descrito acima. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado (Limited Use).

Como revogar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions (TONY → Remover acesso).

In short: read-only access to the owner's Google Calendar, used only to answer the owner; never sold, shared or used for ads; Limited Use requirements apply.
